# Spotipi + Photo

A 64×64 LED matrix display for Raspberry Pi that cycles photos from an Apple
Photos album and switches to Spotify cover art whenever music is playing. A web
UI controls modes (on / off / photos only / Spotify only), live brightness, photo
interval, a screen timer, and a daily schedule. Album deletions sync to the panel
automatically.

**Status:** Deployed
**Stack:** Raspberry Pi · rpi-rgb-led-matrix · Python · Flask · osxphotos

Part of the [xpdr.aero](https://github.com/captaincomplex/captaincomplex.github.io) projects site.
